# Lúmen Agenda

Projeto Flutter da disciplina de Desenvolvimento para Dispositivos Móveis.

O aplicativo tem tela de cadastro/login, um calendário e a lista de tarefas de cada dia. Dá para adicionar tarefa, remover e marcar como concluída. As pendentes ficam em primeiro lugar e, dentro de cada grupo, a ordem é alfabética.

Não usei Firebase. Cadastro, login e tarefas ficam salvos no aparelho com SharedPreferences.

## Como rodar

```
flutter pub get
flutter run
```

Prints das telas: pasta `prints`.
